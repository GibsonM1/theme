# Shared theme for Mr. Gibson's class interactives

`theme-v1.css` holds the Material 3 color, type, and shape tokens plus base components (top app bar, buttons, stepper, fields, snackbar, dialog) that every class interactive links:

```html
<link rel="stylesheet" href="https://gibsonm1.github.io/theme/theme-v1.css">
```

Supports light and dark mode (`prefers-color-scheme`) and reduced motion. If a change would break older games, copy this file to `theme-v2.css` instead of editing it.
